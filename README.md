### Hi, I'm Marchelle 👋

I build websites, web apps and databases for real businesses, start to finish.
I'm self-taught and I work AI-first: I plan the product, then build it with Cursor AI and ship it to production.

Since July 2025 I've run **[Lowveld Web](https://lowveldweb.co.za)**, a small studio in Mbombela. Clients rate it 5.0 from 6 Google reviews.
I've also managed a macadamia farm and a construction workshop. So I'm used to deadlines, budgets and people who need things to work.

I'm now looking for a **full-time remote role** as an AI-assisted full-stack developer.

---

### What I build

- **Business websites** that load fast and bring in enquiries (WhatsApp ordering, quote forms)
- **Web apps** with logins, live data and admin dashboards
- **Simple CMS set-ups** so clients can update their own content
- **Database back ends** on Convex and Supabase, deployed on Vercel

### How I work (Cursor + AI)

1. **Brief first.** I write down who the user is and what "done" looks like before any code.
2. **Build in small steps.** I use Cursor AI to draft code, then read, test and fix it myself.
3. **Ship early.** Every project gets a live Vercel preview so clients can click around from day one.
4. **Hand over cleanly.** Admin panels so clients can update their own content.
